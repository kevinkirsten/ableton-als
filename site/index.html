Inspect, repair and convert Live Sets, right in this tab.

Drop an .als file to see its tracks, scenes and clips, check it for the damage that makes Live refuse or crash, fix it, and turn a Live 12 set into one Live 10 can open.

Drop an .als file anywhere on this page

Your file never leaves this computer. This page has no server, and its security policy forbids every network request, so it could not upload a set if it tried. How to check that yourself.

What this page does

Inspect The Live version that saved the set, its tempo, tracks, scenes and clips with the colours stored in the file, and every audio file it references.
Validate The structural rules Live depends on: one clip slot per scene in every track, automation that points at a real target, routes that lead to a real track. Each problem comes with a stable code and its values.
Convert Live 12 to Live 10. Live has no downgrade path, so the page rebuilds the file the older version expects, including the alias records Live 10 finds audio by.
Repair Duplicate automation Ids, clips warped at the wrong tempo, follow actions out of step, clip geometry that differs between tracks, and samples that point at another machine.

Every action shows the code that does the same thing with the ableton-als library, for the browser and for Node.

Check the privacy claim

  1. Open your browser's developer tools on the Network tab, then open a set and convert it. No request appears.
  2. Load this page, turn Wi-Fi off, and use it. Everything still works.
  3. View the page source. The Content-Security-Policy tag at the top carries connect-src 'none', which makes the browser itself refuse any upload.

What was measured, and what was not

  • Conversion was measured against sets written by Live 10.1.43 and Live 12.4.3 on macOS. A converted 561-scene set opened in Live 10 with no missing files.
  • Alias records are built only for audio under /Volumes/. A set whose audio sits on the startup disk still converts, and Live 10 asks you to locate the audio once.
  • Live 11 sets are not converted. That version has never been measured against a real file, and a guess here produces a set that opens and then crashes.
  • No Windows-authored set has been checked. If you have one that misbehaves, an issue with the file attached is the most useful report there is.
  • Always keep your original file. This page never overwrites it.
